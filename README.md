## Run locally

Open `index.html` in a modern browser. No build step is required.

## Publish with GitHub Pages

1. Upload the repository files to your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder, then save.
5. Wait for GitHub Pages to publish the site.

## Customization

- Main page: `index.html`
- Styles: `css/style.css`
- JavaScript: `js/script.js`
- Graphic design samples: `assets/images/graphic-design/`
- CV: `Shashini_Anjana_CV.pdf`

Remember to check that the contact details and CV are current before publishing.
